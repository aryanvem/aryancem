# Jewelry Store Full-Stack Application

## Overview
This is a full-stack application designed to manage a jewelry store, providing functionalities for both customers and store managers.

## Features
- **User Authentication**: Securely log in and register as customers or store managers.
- **Product Management**: Add, edit, and delete jewelry items through a user-friendly interface.
- **Shopping Cart**: Customers can add items to their cart and proceed with checkout.
- **Order Management**: Store managers can view and manage customer orders.
- **Search and Filter**: Customers can search for specific items or filter by categories.

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript, React
- **Backend**: Node.js, Express
- **Database**: MongoDB
- **Deployment**: Hosted on Heroku (or other specified host)

## Getting Started
1. Clone the repository.
2. Install dependencies using `npm install`.
3. Start the server and visit the app in your browser.
